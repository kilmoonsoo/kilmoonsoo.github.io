GitHub 연결

이 화면은 GitHub 저장소의 설정 파일을 직접 고칩니다. 토큰은 이 기기 브라우저에만 저장되고 GitHub 외 다른 곳으로 보내지 않습니다.

이 기기에 기억하기

토큰 만드는 법

  1. GitHub → 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → autopost
  3. Permissions: Contents: Read and write, Actions: Read and write
  4. 만료일은 90일 정도로, 만료되면 새로 만들어 여기 다시 입력

예약 순서

한국 시간 08~22시에 매시간 확인해서 시간이 된 것을 올립니다(실제 게시는 예약 시각보다 수십 분 늦을 수 있음). 밤 시간 예약은 다음 날 아침 8시대에 올라갑니다. 원고마다 이미 올린 채널은 건너뜁니다.
