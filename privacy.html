문의: fadaugpl@gmail.com

1. 서비스 개요

land3lab-autopost는 운영자 본인의 블로그·인스타그램·스레드·유튜브 채널에 부동산 정보 콘텐츠를 게시하기 위해 운영자가 직접 사용하는 내부 자동화 프로그램입니다. 외부 이용자에게 제공되는 서비스가 아닙니다. 이 프로그램은 YouTube API 서비스를 사용합니다.

2. 이용하는 Google 사용자 데이터

  • 범위: YouTube 동영상 업로드(https://www.googleapis.com/auth/youtube.upload), Blogger 게시(https://www.googleapis.com/auth/blogger)
  • 용도: 운영자 본인 YouTube 채널에 쇼츠 영상을 업로드하고, 운영자 본인 Blogger 블로그에 글을 게시하는 데에만 사용합니다.
  • 다른 사람의 Google 계정 정보, 시청 기록, 구독 정보, 다른 블로그의 글 등은 조회·수집하지 않습니다.
  • 수집한 정보를 제3자(내부·외부)에게 제공하거나 판매하지 않으며, 광고 목적의 쿠키나 기기 정보 수집을 하지 않습니다.

3. 보관 및 보호

인증 정보(토큰)는 운영자의 비공개 저장소 보안 설정(GitHub Secrets)에 암호화되어 보관됩니다. 업로드한 영상과 글은 YouTube·Blogger 정책에 따라 운영자 채널과 블로그에 게시됩니다.

4. 접근 권한 철회 및 삭제

Google 보안 설정 페이지(https://security.google.com/settings/security/permissions)에서 언제든 이 프로그램의 접근 권한을 철회할 수 있습니다. 철회 시 보관 중인 인증 정보는 7일 이내에 삭제하며, 관련 API 데이터는 30일 이내에 삭제합니다.

5. 관련 정책

  • Google 개인정보처리방침
  • YouTube 서비스 약관
  • 본 프로그램의 Google API 정보 사용은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

6. 문의 및 변경

개인정보 관련 문의나 불만은 fadaugpl@gmail.com 로 접수하며 지체 없이 답변합니다. 이 방침이 바뀌면 이 페이지에 시행일과 함께 고지합니다.

land3lab-autopost Privacy Policy

Effective: November 25, 2026
Operator: Land3lab (Land3 Research Institute) · Mihome Gwanak
Contact: fadaugpl@gmail.com

1. Overview

land3lab-autopost is an internal automation tool used only by its operator to publish real-estate information content to the operator's own blog, Instagram, Threads and YouTube channel. It is not offered to outside users. This client uses YouTube API Services.

2. Google user data we use

  • Scopes: https://www.googleapis.com/auth/youtube.upload and https://www.googleapis.com/auth/blogger
  • Purpose: uploading Shorts to the operator's own YouTube channel and publishing posts to the operator's own Blogger blog only.
  • We do not access or collect other users' data, watch history, subscriptions or other blogs' content.
  • We do not share or sell any data to internal or external third parties, and we do not use advertising cookies or collect device information.

3. Storage and protection

OAuth tokens are stored encrypted in the operator's private repository secrets (GitHub Secrets).

4. Revoking access and deletion

You can revoke this client's access at any time via the Google security settings page: https://security.google.com/settings/security/permissions. Stored authorization data is deleted within 7 days of revocation, and related API data within 30 days.

5. Related policies

  • Google Privacy Policy
  • YouTube Terms of Service
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Contact

Privacy questions or complaints: fadaugpl@gmail.com
