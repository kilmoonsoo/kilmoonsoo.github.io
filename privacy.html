1. 서비스 개요

land3lab-autopost는 운영자 본인의 블로그·인스타그램·스레드·유튜브 채널에 부동산 정보 콘텐츠를 게시하기 위해 운영자가 직접 사용하는 내부 자동화 프로그램입니다. 외부 이용자에게 제공되는 서비스가 아닙니다.

2. 이용하는 Google 사용자 데이터

  • 범위: YouTube 동영상 업로드 권한 (https://www.googleapis.com/auth/youtube.upload)
  • 용도: 운영자 본인 YouTube 채널에 프로그램이 만든 쇼츠 영상을 업로드하는 데에만 사용합니다.
  • 다른 사람의 Google 계정 정보, 시청 기록, 구독 정보 등은 조회하거나 수집하지 않습니다.

3. 보관 및 보호

  • 인증 정보(토큰)는 운영자의 비공개 저장소 보안 설정(GitHub Secrets)에 암호화되어 보관되며, 제3자에게 제공하거나 판매하지 않습니다.
  • 업로드한 영상은 YouTube 정책에 따라 운영자 채널에 게시됩니다.

4. 접근 권한 철회 및 삭제

운영자는 Google 계정 > 보안 > 서드 파티 연결(myaccount.google.com/permissions)에서 언제든 접근 권한을 철회할 수 있으며, 철회 시 보관 중인 인증 정보는 즉시 삭제합니다.

5. Google API 서비스 사용자 데이터 정책 준수

본 프로그램의 Google API 정보 사용은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
